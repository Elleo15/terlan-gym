## ✨ Features

- **3 Languages** — Azerbaijani, Russian, English (instant switch)
- **Hero Video** — Autoplay background video with overlay
- **Parallax Effect** — Smooth scroll parallax on hero section
- **Scroll Animations** — Elements reveal on scroll
- **Counter Animation** — Animated statistics numbers
- **Custom Cursor** — Gold cursor with follower effect (desktop)
- **WhatsApp Booking** — Form submits directly to WhatsApp
- **FAQ Accordion** — Expandable FAQ section
- **Responsive** — Mobile, tablet and desktop optimized
- **Open Graph** — Social media sharing preview
- **Loader** — Branded loading screen
- **Sticky Navbar** — Transparent → dark on scroll

## 🚀 Deployment (GitHub Pages)

1. Create a new GitHub repository
2. Upload all files keeping the folder structure
3. Go to **Settings → Pages**
4. Set Branch to `main`, folder to `/ (root)`
5. Click **Save**
6. Site will be live at `https://USERNAME.github.io/REPO-NAME`
